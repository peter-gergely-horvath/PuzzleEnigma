# 🧩 Puzzle Enigma - Brain Teaser Memory Games

A collection of 10 interactive brain teaser memory games built with HTML, CSS, and JavaScript. Challenge your mind with various memory and pattern recognition games!

## 🎮 Games Included

1. **Classic Memory (Pairs)** - Flip cards to match pairs of images
2. **Simon Says** - Remember and repeat sequences of colors/sounds
3. **Number Sequence** - Remember increasingly long number sequences
4. **Pattern Grid** - Remember positions of highlighted tiles in a grid
5. **Word Memory** - Remember and recall lists of words
6. **Color Sequence** - Remember order of colored blocks
7. **N-Back Game** - Remember items from N steps back in a sequence
8. **Speed Matching** - Quick-fire card matching against the clock
9. **Picture Differences** - Find what changed between two images
10. **Sequence Builder** - Rebuild a pattern shown briefly

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click on any game card to start playing!

## 🎨 Features

- **Modern UI Design** - Sleek dark theme with gradient accents
- **Responsive Layout** - Works on desktop, tablet, and mobile devices
- **Progressive Difficulty** - Games get harder as you progress
- **Score Tracking** - Best scores saved in browser localStorage
- **Smooth Animations** - Polished transitions and effects
- **Accessibility** - Keyboard navigation support

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript (ES6+)
- LocalStorage API for score persistence
